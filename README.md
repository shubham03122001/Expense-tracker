UserService - Manage User Information
Overview
The UserService is responsible for managing user information such as first name, last name, phone number, and email. It allows storing user data and provides the ability to fetch user details based on their unique userID. This service ensures that all user information is stored securely and can be retrieved when needed.

Key Features
Store User Information: Allows saving user details such as firstName, lastName, phoneNumber, and email.

Fetch User Details: Retrieves the user information based on the userID.

Basic Validation: Validates the input data to ensure correct formatting for fields like email and phone number.
